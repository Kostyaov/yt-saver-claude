📝 Налаштування Firebase

⚠️ Потрібно налаштувати Firebase Config

Для роботи розширення необхідно налаштувати файл firebase-config.js

Детальні інструкції у файлі FIREBASE_SETUP.md

Швидкий старт:

  1. Створіть проєкт у Firebase Console
  2. Увімкніть Firestore Database
  3. Отримайте Firebase Config (Web App)
  4. Відкрийте файл extension/utils/firebase-config.js
  5. Замініть placeholder значення на ваші дані з Firebase
  6. Перезавантажте розширення

Приклад конфігурації:

const FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};

⌨️ Клавіатурні скорочення

Зберегти закладку: Ctrl+Shift+B (⌘+Shift+B на Mac)

Натисніть комбінацію клавіш під час перегляду відео на YouTube, щоб відкрити вікно збереження закладки.

Для зміни клавіатурних скорочень перейдіть до chrome://extensions/shortcuts

ℹ️ Про розширення

Версія: 2.0.0 (Firebase)

Backend: Firebase Firestore

Опис: Розширення для збереження улюблених моментів з YouTube у Firebase Firestore.

Переваги Firebase версії:

  • 🚀 Швидше - в 10+ разів швидше ніж Google Sheets
  • ✅ Простіше - без OAuth головного болю
  • ⚡ Real-time - миттєва синхронізація
  • 📱 Offline - працює без інтернету
  • 💚 Безкоштовно - щедрий безкоштовний план

Структура даних:

  • Collection: bookmarks
  • Поля: title, watchUrl, description, category, channelUrl, currentTime, createdAt
