    ℹ️ Про розширення

    Версія: 3.0.0 (IndexedDB / Local)

    Сховище: IndexedDB (Browser Local Storage)

    Опис: Розширення для збереження улюблених моментів з YouTube в локальне сховище браузера.

    Переваги Local версії:

    • 💾 Локальне збереження - все на вашому пристрої
    • ⚡ Швидше - немає мережевих запитів
    • 🔒 Приватно - дані не покидають браузер
    • 📴 Offline - працює без інтернету
    • 💰 Безкоштовно - не потрібні зовнішні сервіси
    • 📤 Експорт/Імпорт - легко переносити дані

    Структура даних:

    • Database: youtube-bookmarks (IndexedDB)
    • Object Store: bookmarks
    • Поля: title, watchUrl, description, category, channelUrl, currentTime, createdAt
