# 🔄 Міграція даних з Google Sheets в Firebase

Цей інструмент допоможе перенести ваші існуючі закладки з Google Sheets в Firebase Firestore.

## 📋 Покрокова інструкція

### Крок 1: Експорт даних з Google Sheets

1. Відкрийте вашу Google Таблицю з закладками
2. Для кожної сторінки (теми):
   - **File** → **Download** → **Comma Separated Values (.csv)**
   - Або **Файл** → **Завантажити** → **CSV**
   - Збережіть файл з назвою теми (наприклад: `Python.csv`)
3. Повторіть для кожної теми

### Крок 2: Запуск міграційного інструменту

1. Відкрийте файл `migrate-to-firebase.html` в браузері
2. Заповніть **Firebase Config**:
   - **API Key** - з файлу `extension/utils/firebase-config.js`
   - **Project ID** - з того ж файлу
3. Для кожної теми:
   - Скопіюйте вміст CSV файлу
   - Вставте в поле "CSV Дані"
   - Введіть назву категорії (наприклад: "Python")
   - Натисніть **"Почати міграцію"**
4. Зачекайте завершення міграції

### Крок 3: Перевірка даних

1. Перейдіть до [Firebase Console](https://console.firebase.google.com/)
2. Виберіть ваш проєкт
3. **Firestore Database** → вкладка **"Data"**
4. Перевірте, чи всі закладки успішно мігрували

## 🔍 Формат CSV

Інструмент очікує CSV у наступному форматі:

```csv
Назва відео,Подивитися,Опис,Канал,Дата додавання
Python Tutorial,https://youtu.be/abc123?t=60,Great tutorial,https://youtube.com/c/channel,2024-01-01
```

**Важливо:**
- Перший рядок - заголовки колонок
- Колонки розділені комою
- Якщо в значенні є кома, обгорніть його в лапки: `"Title, with comma"`

## ⚠️ Обмеження

- Міграція виконується по одному запису за раз
- Для великих таблиць (1000+ записів) це може зайняти час
- Є невелика затримка між запитами (100ms) для уникнення rate limiting

## 💡 Поради

1. **Зробіть backup:**
   - Експортуйте Google Sheets в Excel формат
   - Зберігайте копію CSV файлів

2. **Міграція частинами:**
   - Мігруйте по одній темі за раз
   - Перевіряйте результат після кожної теми

3. **Помилки:**
   - Якщо запис не мігрувався, перевірте формат
   - Переконайтеся, що всі поля заповнені

## 🔧 Ручна міграція

Якщо автоматична міграція не працює, можна мігрувати дані вручну:

1. Відкрийте Firebase Console
2. Firestore Database → вкладка "Data"
3. Створіть колекцію "bookmarks"
4. Додайте документи вручну з полями:
   - title, watchUrl, description, category, channelUrl, currentTime, createdAt

## 📊 Структура даних

### Google Sheets (старий формат):
```
Назва відео | Подивитися | Опис | Канал | Дата
```


## ❓ FAQ

**Q: Чи можна мігрувати кілька тем одночасно?**
A: Ні, міграція відбувається по одній темі за раз для уникнення помилок.

**Q: Що робити якщо міграція перервалася?**
A: Просто запустіть міграцію знову для цієї ж теми. Firebase не створить дублікатів.

**Q: Скільки часу займає міграція?**
A: ~100-200 записів на хвилину. Для 1000 записів - близько 5-10 хвилин.

**Q: Чи видаляються дані з Google Sheets?**
A: Ні! Дані в Google Sheets залишаються без змін. Вони лише копіюються в Firebase.

**Q: Що якщо є помилка "Permission denied"?**
A: Перевірте правила безпеки Firestore. Вони мають дозволяти запис.
