# 🚀 Швидке налаштування YouTube Bookmarks Saver

**Версія:** 3.0.0 (IndexedDB Local Storage)

---

## ⚡ Переваги цієї версії

- ✅ **Нульова конфігурація** - працює одразу після встановлення
- ✅ **Без OAuth** - не потрібні облікові записи Google
- ✅ **Без API ключів** - немає залежностей від зовнішніх сервісів
- ✅ **Повна приватність** - всі дані зберігаються локально
- ✅ **Офлайн режим** - працює без інтернету
- ✅ **Швидкість** - збереження <50ms

---

## Крок 1: Клонування репозиторію

```bash
git clone https://github.com/yourusername/yt-saver-claude.git
cd yt-saver-claude
```

---

## Крок 2: Встановлення розширення

### Chrome / Edge / Brave / Opera

1. **Відкрийте сторінку розширень:**
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
   - Opera: `opera://extensions/`

2. **Увімкніть режим розробника:**
   - Знайдіть перемикач "Developer mode" / "Режим розробника" у правому верхньому куті
   - Увімкніть його

3. **Завантажте розширення:**
   - Натисніть "Load unpacked" / "Завантажити розпаковане"
   - Виберіть папку `extension/` з репозиторію
   - Натисніть "Select Folder" / "Вибрати папку"

4. **Готово!** 🎉
   - Розширення встановлено та активовано
   - Жодних додаткових налаштувань не потрібно
   - Можете одразу користуватися

## Крок 3: Перша закладка

### Спосіб 1: Клавіатурне скорочення

1. Відкрийте будь-яке відео на YouTube
2. Натисніть `Ctrl+Shift+B` (Windows/Linux) або `Cmd+Shift+B` (Mac)
3. Виберіть категорію та додайте опис (за бажанням)
4. Натисніть "Зберегти"

### Спосіб 2: Через іконку розширення

1. Відкрийте будь-яке відео на YouTube
2. Натисніть на іконку розширення в панелі браузера
3. Виберіть категорію та додайте опис (за бажанням)
4. Натисніть "Зберегти"

---

## Крок 4: Перегляд збережених закладок

### Спосіб 1: Через popup

1. Натисніть на іконку розширення **на будь-якій сторінці**
2. Внизу знайдіть кнопку **"📖 Збережене"**
3. Натисніть на неї - відкриється сторінка з усіма закладками

### Спосіб 2: Пряме посилання

Відкрийте в браузері:
```
chrome-extension://[ваш-id-розширення]/bookmarks/bookmarks-viewer.html
```

Щоб дізнатись ID розширення:
1. Відкрийте `chrome://extensions/`
2. Знайдіть "YouTube Bookmarks Saver"
3. ID вказаний під назвою

---

## Крок 5: Налаштування (опціонально)

### Відкриття налаштувань

1. Натисніть на іконку розширення
2. Внизу натисніть **"⚙️ Налаштування"**

або

1. Відкрийте `chrome://extensions/`
2. Знайдіть "YouTube Bookmarks Saver"
3. Натисніть "Details" → "Extension options"

### Що можна налаштувати

#### Категорії
- Додати нові категорії (Програмування, Arduino, Python, тощо)
- Категорії зберігаються автоматично

#### Експорт даних
- Завантажити всі закладки у JSON форматі
- Формат: `youtube-bookmarks-YYYY-MM-DD.json`
- Використовуйте для резервного копіювання

#### Імпорт даних
- Відновити закладки з JSON файлу
- Корисно при переході на інший комп'ютер
- Або при переустановці браузера

#### Очистка даних
- Видалити всі закладки (з підтвердженням)
- **Обережно:** Операція незворотна!
- Рекомендується спочатку експортувати дані

## Функції перегляду закладок

### Пошук
- Введіть текст у поле пошуку
- Пошук працює по:
  - Назві відео
  - Опису закладки
  - Назві каналу
  - Категорії
- Результати оновлюються миттєво

### Фільтрація
- Виберіть категорію з випадаючого списку
- Показуються лише закладки цієї категорії
- "Всі категорії" - показати всі

### Сортування
- **Найновіші** - нові закладки зверху (за замовчуванням)
- **Найстаріші** - старі закладки зверху
- **За назвою** - alphabetically по назві відео
- **За категорією** - групування по категоріях

### Видалення
- Натисніть кнопку 🗑️ біля закладки
- Підтвердіть видалення
- Закладка буде видалена назавжди

## Поширені питання

### Де зберігаються мої дані?

Всі дані зберігаються **локально** у вашому браузері в IndexedDB:
- База даних: `youtube-bookmarks`
- Розташування: Browser Profile → IndexedDB
- Доступ: Тільки це розширення
- Розмір: До 50-100 МБ (залежить від браузера)

### Чи синхронізуються дані між пристроями?

Ні, дані зберігаються локально на кожному пристрою окремо.

**Для переносу даних між пристроями:**
1. Експортуйте закладки на першому пристрої
2. Перенесіть JSON файл (email, USB, хмара)
3. Імпортуйте на другому пристрої

### Що станеться якщо видалити розширення?

При видаленні розширення **всі дані будуть втрачені** (якщо не збережені в налаштуваннях браузера).

**Рекомендації:**
1. Експортуйте дані перед видаленням
2. Зберігайте резервні копії
3. При переустановці просто імпортуйте дані назад

### Як переглянути базу даних?

**Chrome DevTools:**
1. Відкрийте DevTools (F12)
2. Вкладка "Application"
3. Розділ "Storage" → "IndexedDB" → "youtube-bookmarks"
4. Об'єкт "bookmarks" - всі ваші закладки

### Скільки закладок можна зберегти?

Технічні обмеження:
- **Типово:** ~1000-5000 закладок без проблем
- **Максимум:** Залежить від квоти браузера (~50-100 МБ)
- **Рекомендація:** Якщо понад 10,000 - робіть експорт частинами

### Чи працює без інтернету?

**Так!** Розширення повністю працює офлайн:
- ✅ Збереження закладок
- ✅ Перегляд закладок
- ✅ Пошук та фільтрація
- ✅ Експорт даних
- ❌ Потрібен інтернет тільки для перегляду відео на YouTube

## Налагодження

### Розширення не з'являється

1. Перевірте що увімкнено "Developer mode"
2. Перезавантажте сторінку розширень (F5)
3. Спробуйте "Load unpacked" ще раз
4. Перевірте що вибрана папка `extension/`, не корінь репозиторію

### Закладки не зберігаються

1. Перевірте консоль браузера (F12) на помилки
2. Відкрийте `chrome://extensions/` → Details → Inspect views: service worker
3. Перевірте IndexedDB: DevTools → Application → IndexedDB → youtube-bookmarks
4. Перезавантажте розширення

### Кнопки "Збережене" та "Налаштування" не працюють

1. Перезавантажте розширення
2. Закрийте та відкрийте popup знову
3. Перевірте консоль на помилки JavaScript
4. Переустановіть розширення

### Імпорт JSON не працює

1. Перевірте формат JSON (має бути валідний)
2. Перевірте версію (`"version": "3.0.0"`)
3. Перевірте розмір файлу (не більше 50 МБ)
4. Спробуйте імпортувати меншими частинами
