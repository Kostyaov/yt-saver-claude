## [1.0.0] - 2024-11-08

### Додано

#### Основний функціонал
- 📚 Збереження закладок YouTube відео у Google Таблиці
- 🎯 Підтримка збереження початку та кінця фрагментів відео
- 🏷️ Організація закладок за темами (категоріями)
- ⌨️ Клавіатурне скорочення `Ctrl+Shift+B` для швидкого збереження
- 📝 Можливість додавання власних описів до закладок

#### Інтеграція з YouTube
- Автоматичне отримання назви відео
- Автоматичне отримання назви каналу
- Автоматичне отримання опису відео
- Відстеження поточного часу відео
- Підтримка форматування часу (чч:хх:сс)

#### Інтеграція з Google Sheets
- OAuth 2.0 авторизація через Google Identity API
- Автоматичне створення нової таблиці
- Можливість підключення існуючої таблиці
- Автоматичне створення окремих сторінок (sheets) для кожної теми
- Форматування заголовків таблиці (колір фону, жирний текст)
- Структура даних: URL, Назва, Початок, Кінець, Опис, Опис відео, Канал, Дата

#### Інтерфейс користувача
- Popup вікно з формою збереження закладок
- Сторінка налаштувань з управлінням:
  - Авторизацією Google
  - Google Таблицею
  - Темами
  - Інформацією про розширення
- Відображення поточної інформації про відео
- Попередній перегляд даних перед збереженням
- Лічильник символів для опису
- Відображення статусу операцій

#### Управління темами
- Додавання нових тем через popup
- Додавання нових тем через налаштування
- Видалення тем
- Збереження списку тем у Chrome Storage
- Типові теми за замовчуванням (Програмування, Python, Arduino, Web Development, JavaScript)

#### Технічні особливості
- Manifest V3 (найновіша версія Chrome Extensions API)
- Content Script для інтеграції з YouTube
- Background Service Worker для роботи з Google Sheets API
- Модульна архітектура коду
- Обробка помилок та відображення статусу операцій
- Кешування даних у Chrome Storage
